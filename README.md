# 句乐部 · 本地英语学习站

这是一个无依赖的个人英语学习网页，适合在本地电脑中作为独立学习入口使用。

## 已实现

- 每日打卡与连续学习天数
- 每日任务及自动同步完成状态
- 新概念、KET、PET、FCE、四六级、剑桥考试和中高考课程包
- 单课词汇、句子朗读、随堂练习、课程进度
- KET、PET、FCE 对应的 12 / 16 / 20 周备考计划
- 内置 KET、PET、FCE 原创听力、阅读、理解题与完成记录，无须跳转网站
- 掌握列表、复习本、生词本和成长分析
- 所有学习数据自动保存到当前浏览器的本地存储

## 使用方式

在 macOS 上，双击 `启动句乐部.command` 即可打开网页；保持弹出的终端窗口开启，学习站就会持续运行。

也可以在此目录手动启动本地静态网页服务：

   ```bash
   python3 -m http.server 4173
   ```

然后在浏览器访问 `http://localhost:4173`。

需要恢复演示数据时，在浏览器开发者工具的“应用程序 / 本地存储”中删除键 `jule-club-learning-v1`，再刷新页面。

听力使用浏览器本身的英语语音朗读功能；所有学习记录只保存在本机浏览器。备考计划依据剑桥英语考试对应的 CEFR 能力目标设计，但不属于 Cambridge 官方课程或真题。
